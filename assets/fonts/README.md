# Fontes do cartão de compartilhamento

Usadas pelo `ShareCardService` (satori) para gerar a imagem de preview
1200×630 de certificados (`GET /trainee-certificate/public/:key/og.png`).

| Arquivo | Origem | Licença |
|---|---|---|
| `Montserrat-Regular.ttf` | fontsource `montserrat@5.2.5` latin-400-normal | SIL OFL 1.1 |
| `Montserrat-Bold.ttf` | fontsource `montserrat@5.2.5` latin-700-normal | SIL OFL 1.1 |
| `BebasNeue-Regular.ttf` | fontsource `bebas-neue@5.2.5` latin-400-normal | SIL OFL 1.1 |

Subconjunto *latin* (cobre os acentos do português). São as mesmas famílias
usadas nos modelos de certificado (`fontConfig.ts` no front).
